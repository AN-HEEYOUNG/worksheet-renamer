# 작업지시서 스타일넘버 자동 인식 · 파일명 변환기

작업지시서를 스캔한 이미지에서 **STYLE NO.(8자리 스타일넘버)** 를 자동으로 읽어 파일명을 바꿔주는 도구입니다.
설치·서버·인터넷 연결이 전혀 필요 없는 **단일 HTML 파일**로 동작하며, 모든 처리는 브라우저 안에서만 이루어집니다.
파일이 외부로 전송되는 일은 없습니다.

▶ **바로 써보기**: GitHub Pages로 배포된 버전을 열면 설치 없이 바로 사용할 수 있습니다. (저장소 상단 About 또는 Settings → Pages에서 링크 확인)

---

## 왜 만들었나

작업지시서는 종이에 손으로 작성한 뒤 복합기로 스캔해서 공유폴더에 올립니다. 기존에는 이미지를 하나씩 열어
좌측 상단의 8자리 스타일넘버를 사람이 직접 읽고 타이핑해서 파일명을 바꿔야 했고, 이 단계가 가장 오래 걸렸습니다.
이 도구는 그 단계만 자동화합니다 — 스캔 폴더 접근이나 연도별 분류 같은 나머지 과정은 그대로 두고, "이미지를 보고 이름을 타이핑하는" 부분만 대신해 줍니다.

### 스타일넘버 규칙 (예시)

8자리, 예: `AB1C2345` (실제 값이 아닌 형식 예시입니다)

- 1번째 자리: 성별/구분 코드 (예: 남성/여성)
- 2번째 자리: 연도 코드
- 3번째 자리: 시즌 코드
- 4번째 자리: 분류 문자
- 5~8번째 자리: 숫자 품번

자리별로 어떤 문자를 허용할지는 도구 설정 화면에서 쉼표로 구분해 직접 조정할 수 있습니다 (예: `A-Z,0-9`, `C,J,0-9`, `KR`).

## 사용 방법

1. **불러오기** — 스캔한 이미지를 화면에 끌어다 놓거나, "폴더에서 바로 불러오기"로 폴더 전체를 불러옵니다.
2. **확인** — 각 파일의 STYLE NO. 8칸이 크게 표시됩니다. 자동 인식된 칸은 그대로 두고, 확인이 필요한 칸(주황색)만 보고 타이핑합니다. 점수가 낮거나(빨간 글씨) 학습 샘플이 적은 글자는 일부러 자동으로 채우지 않습니다 — 오인식보다 확인이 우선입니다.
3. **저장** — "이름 바꿔서 저장"을 누르면 이름이 바뀐 파일들이 ZIP으로 저장됩니다. 브라우저가 지원하면 ZIP 없이 선택한 폴더 안에서 바로 이름을 바꾸는 것도 가능합니다.
4. **학습** — 직접 입력한 글자는 브라우저에 학습되어 다음부터 자동 인식됩니다. 설정에서 학습 데이터를 내보내기/불러오기 해서 여러 사람의 학습을 합칠 수 있습니다.

브라우저 저장(학습 데이터, 설정값)은 기기별로 개별 저장됩니다. 공유되지 않으니, 여러 사람이 함께 쓴다면 주기적으로 "학습 내보내기/불러오기"로 동기화하는 것을 권장합니다.

## 동작 원리 (요약)

```
이미지 로드
  → 좌상단 관심영역만 캔버스에 렌더 → 회색조 배열
  → 격자 검출로 STYLE NO. 8칸의 좌표를 찾음
  → 칸별로 글자를 잘라 32x32로 정규화 (z-정규화 → 상관계수 기반 유사도)
  → 학습된 템플릿과 비교 (자리별로 허용된 문자만 후보)
  → 점수 ≥ 임계값 이고, 학습 샘플이 충분하고, 다음 후보와 점수 차이가 충분할 때만 자동 채택
  → 그 외에는 비워두고 사람이 입력 (입력한 글자는 다시 학습됨)
  → ZIP으로 저장 (또는 폴더 직접 변경)
```

핵심 설계 원칙은 **"확신 없으면 절대 채우지 않는다"** 입니다. 자동 인식은 점수(유사도)뿐 아니라
① 해당 글자의 학습 샘플 개수, ② 1등·2등 후보의 점수 차이(마진) 까지 함께 통과해야 확정됩니다.
학습 샘플이 적은 글자(예: 드물게 나오는 문자)는 점수가 높아도 사람 확인을 거치도록 되어 있습니다.

격자 검출은 "폭이 가장 고른 연속된 9개 세로선"을 찾는 방식으로, 라벨 칸이나 옆 칸이 섞여 들어오는 것을 자연히 배제합니다.

### 코드 구조

단일 HTML 파일(`index.html`)이며 `<script>` 안이 구역별로 나뉘어 있습니다.

| 구역 | 주요 함수 | 역할 |
|---|---|---|
| 설정 | `RULES`, `THRESHOLD`, `SEED` | 자리별 허용 문자, 임계값, 내장 학습 데이터 |
| 격자 검출 | `groupRuns`, `readROI`, `findGrid` | STYLE NO. 8칸 좌표 찾기 |
| 글자 정규화·인식 | `extractGlyph`, `quantize`, `recognize`, `learn` | 인식 엔진 |
| 학습 저장 | `tplToJSON`, `tplFromJSON`, `saveTpl`, `loadTpl` | localStorage 및 파일 입출력 |
| 파일 처리 | `loadImage`, `addFiles`, `analyze`, `nameOf` | 파일 → 결과 |
| 화면 | `render`, `refreshCard`, `updateBar` | UI |
| 저장 | `crc32`, `makeZip`, `saveAll`, `folderMode`, `saveToFolder` | 출력 |

`window.__app`에 테스트 훅이 노출되어 있습니다 (`analyze`, `items`, `learn`, `templates`, `nameOf`).

## 알려진 제약

- PDF는 지원하지 않습니다 (JPG/PNG만).
- 학습 데이터와 설정은 브라우저(기기)별로 저장되며 자동으로 공유되지 않습니다.
- "폴더에서 바로 변경" 기능은 `showDirectoryPicker`를 지원하는 브라우저(Chrome, Edge 등)에서만 나타납니다. 지원하지 않으면 ZIP 다운로드 방식만 사용됩니다.
- 격자 검출·인식 파라미터는 현재 확보한 샘플 양식 기준으로 맞춰져 있습니다. 다른 양식(예: 하의 작업지시서)에서는 재검증이 필요할 수 있습니다.

## 로컬에서 사용하기

이 저장소를 클론하거나 `index.html`(또는 함께 포함된 도구 파일)만 내려받아 더블클릭으로 열면 됩니다. 설치가 필요 없습니다.
네트워크 공유 경로에서 직접 열면 브라우저 보안 제약으로 일부 기능(폴더 직접 저장 등)이 제한될 수 있으니, 로컬 디스크로 복사한 뒤 여는 것을 권장합니다.

---

이 도구는 외부 서버·API 없이 순수 브라우저(HTML/CSS/JS)로 동작하며, 처리하는 이미지나 학습 데이터는 사용자의 브라우저 밖으로 전송되지 않습니다.
